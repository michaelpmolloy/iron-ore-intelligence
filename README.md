# Iron Ore Intelligence Platform

> WA's budget runs on iron ore. This platform follows it from the mine to the port to the state's royalty cheque, and tracks the ships carrying it in near real time.

**Status:** building (Oct 2026 – Jul 2027). Part 1 *Follow the Ore* (batch) ships Jan 2027; Part 2 *Iron Ore Nowcast* (streaming + ML) ships Apr–Jul 2027.

**Stack:** Azure · Databricks · Delta · Unity Catalog · dbt · ADF · Lakeflow Jobs · Event Hubs · MQTT · Terraform · GitHub Actions · Power BI
